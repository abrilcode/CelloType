What to upload

Upload one multichannel file (all channels in a single file, for example a CZI), or the separate single-channel files of the same image.

For separate files, give each the same base name and a different marker suffix, name-MARKER.ext, for example sample-DAPI.tif and sample-CD3.tif. Single-channel TIFFs that share the base name are read as the channels of one image.

Accepted: CZI, TIFF, PNG, JPEG. PNG and JPEG are 8-bit, so their intensities are not quantitative.

Segment

Objects cut by the image border have a smaller area and lower total intensity than complete ones, so by default they are left out of the table, plots and statistics. They stay visible with an orange outline and keep their number. You can change this after segmenting; no new segmentation is needed.

Optional, off by default. Per image and channel, the median of the pixels outside all objects, leaving out a 5-pixel margin around them, is subtracted from Mean gray value and Integrated density. Other measurements use the original values. Objects dimmer than the background get negative values. The subtracted value is in the background column. The validation of this tool used images without background subtraction or any other preprocessing: turn this on only if you decide it suits your images, and keep the same setting for every image you compare, including the controls.

How to name your files

Name each file condition-Foto<n>-marker.ext, for example FN-D0-Foto1-DAPI.tif. Each image is one Foto<n> inside a condition.

Upload one multichannel file per image (for example FN-D0-Foto1.czi, all channels inside), or the separate single-channel files of that image.

Separate single-channel .tif files that share the same condition-Foto<n> name are read as the channels of one image. This grouping applies only to single-channel TIFFs, not to CZI or multichannel TIFF (which already hold all their channels).

Accepted: CZI, TIFF, PNG, JPEG. PNG and JPEG work for counting but are 8-bit, so their intensities are not quantitative.
